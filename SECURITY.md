# Security Policy

## Supported Versions

We currently maintain the latest version of the Docker image published on the `main` branch. Please update to the newest release before reporting issues.

## Reporting a Vulnerability

1. Use the GitHub Security Advisories form: `https://github.com/justmobilesec/just-mobile-security-mobile-docker/security/advisories/new`.
2. Provide detailed reproduction steps, affected components (Android tools, iOS tools, network tooling), and any proof-of-concept material.
3. Include mitigation ideas if you have them. This helps us respond faster.

If you cannot access the GitHub advisory workflow, leave a note on the repository's Discussions board indicating that you need an alternate disclosure channel and a maintainer will reach out privately.

## Response Process

- We aim to acknowledge new reports within 5 business days.
- We will work with you to understand the issue and plan a remediation.
- Once a fix is ready, we will credit you in the release notes if you agree.

Please follow responsible disclosure and do not publicly share details until we have published a fix.
